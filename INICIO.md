# Cómo iniciar NEXA

**No hace falta `npm install`.** Solo Node.js 20+.

## PowerShell

```powershell
cd "C:\Users\Maria Lara\source\repos\VentaCursos"
git pull origin main
node server/index.js
```

Abrí http://localhost:3000

O doble clic en **`iniciar.bat`**.
